Publishing · Digital library — Kathok Library

A protected online library
for Tibetan texts.

Rare Tibetan books, previously only in print and loose files, now readable on phone and desktop — with protection so the content can't simply be copied or downloaded.

EPUB
read in the browser
AES-256
per-user encryption
Web + iOS
reading sync
The problem

The publisher wanted readers worldwide — including mainland China — to read their Tibetan collection online, on any device, without the books being easy to download and redistribute.

What we built
  • Reader: EPUB books open directly in the browser, with Tibetan script support and a mobile-friendly layout that installs to a phone's home screen.
  • Protection: books are encrypted per user; offline downloads are tied to device-specific licenses.
  • Library: personal collections, favorites, and reading progress that syncs across devices.
  • Publisher tools: upload books, edit metadata, and control visibility and download permissions.
Stack
  • Node.js + Express
  • PostgreSQL
  • React + EPUB.js
  • AES-256 DRM
  • JWT auth
  • Offline-first progress sync
  • Native iOS reader
  • Google Cloud
